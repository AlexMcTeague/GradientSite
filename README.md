<h2>GradientSite</h2>
This is a small project made for Code: You

This project was inspired by my time running a Minecraft server. In Minecraft, you can change the color of individual characters, but not display a gradient within individual characters. Despite this, making gradients across whole words or sentences always wowed the players and made server messages look much fancier than they actually were (in reality they were just generated with standard server plugins). This website mimicks the look of those gradients, this time built from scratch by yours truly.
